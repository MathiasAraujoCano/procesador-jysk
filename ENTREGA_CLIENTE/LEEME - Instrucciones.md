# 🚀 PROCESADOR DE LOTES JYSK - INSTRUCCIONES PARA EL USUARIO

## 📋 CÓMO USAR EL PROGRAMA

### ¡Es muy simple! Solo 3 pasos:

1. **Hacer doble clic** en `ProcesadorLotes_JYSK.exe`
2. **Seleccionar archivo Excel** cuando aparezca la ventana
3. **¡Listo!** El archivo procesado se guardará automáticamente

### 📄 ¿Qué hace el programa?

- ✅ **Elimina automáticamente**: Transacciones denegadas, reversadas y anuladas
- ✅ **Mantiene**: Las devoluciones (no las elimina)
- ✅ **Organiza**: Por fecha, lote, caja y tipo de tarjeta
- ✅ **Colores**: Cada caja tiene su color para fácil identificación
- ✅ **Subtotales**: Calcula totales por lote automáticamente

### 📂 ¿Dónde se guarda el resultado?

El archivo procesado se guarda en la **misma carpeta** que el archivo original con nombre:
`resumen_DDMMYYYY_HHMM.xlsx`

Ejemplo: `resumen_29092024_1430.xlsx`

### ⚠️ PRIMERA VEZ - Windows Defender

La primera vez que ejecutes el programa, Windows puede mostrar una advertencia:

1. **Si aparece "Windows Defender SmartScreen"**:
   - Clic en "Más información"
   - Clic en "Ejecutar de todas formas"

2. **Si aparece "Este archivo puede dañar el equipo"**:
   - Clic en "Mantener" o "Conservar"

**Esto es normal** - Windows siempre advierte sobre programas nuevos.

### 🔧 Si algo no funciona:

1. **El programa no abre**:
   - Clic derecho → "Ejecutar como administrador"

2. **No aparece la ventana para seleccionar archivo**:
   - Verificar que no haya ventanas ocultas en la barra de tareas
   - Cerrar Excel si está abierto

3. **Error al procesar**:
   - Verificar que el archivo Excel no esté abierto en Excel
   - Verificar que el archivo tenga las columnas correctas
